A faster drop-in for makefun-site 1.0.0: byte-identical output, built by a single-pass fused renderer — one scan per document, table-driven HTML escaping, compiled templates, zero per-character allocation churn.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`), answers each with `run` from `solve.js`, and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
